2D 图像

局部编辑、参考控制、文字与品牌变体已进入窄场景生产

分层源文件、复杂排版与严格品牌规则仍依赖工具层

生成成熟，交付取决于上下文与治理
单张图片的生成和局部修改已稳定可用；但要成为正式资产，仍需项目风格、品牌规则、源文件结构、命名、审核和版权记录。

语音 / 配音

本地化、旁白与角色语音已有量化交付

选角、混音、权利与发行仍属专业流程

窄场景成熟，完整制作仍需人工
旁白、本地化和角色台词等明确任务已能稳定提效；选角、情绪表演、混音、授权与最终发行仍由专业人员负责。

视频

分镜、补镜、预演与短广告已经可用

跨镜头一致、精确表演、审片与后期结构未闭环

镜头级可用，项目级仍需人工
一个短镜头可生成、补拍或修改到可采用程度；多个镜头组成完整项目时，人物、场景、动作、光线和叙事连续性仍需人工控制。

3D / 动作

生成、贴图、动捕与专业软件接入持续推进

拓扑、骨骼、LOD、碰撞、性能预算与引擎往返不稳定

进入流程，不等于可直接上线
结果已能导入 Blender、Maya 或游戏引擎继续加工；但拓扑、骨骼、碰撞、LOD、材质和性能预算通常还未一次满足上线标准。

UI / Spine

原型、活动页与孤立特效可明显提速

组件语义、状态、时间轴、遮罩、循环与性能规则缺少通用闭环

可辅助，不宜按演示外推成熟度
原型、局部界面和单个动效可提速；复杂组件状态、骨骼时间轴、遮罩、循环和运行性能仍缺少稳定通用方案。

世界模型

互动预演、空间草模与训练环境进展快

完整游戏世界与工程资产离稳定替代仍远

长期必经方向，不是当前团队主战场
它适合互动预演、空间草模和训练环境；离可编辑、可维护、符合游戏或工程规范的正式资产还有距离，当前投入回报不如生产最后一公里明确。

判断 成熟度节点点亮，只表示至少一条公开路径走通，不代表能满足该领域全部生产需求

行业判断

竞争力不在单次生成质量，而在把标准、资产与反馈沉淀为生产系统，让下一次同类合格资产交付得更快。

03

当前重点推进

把 AI 生图一致性，从提示词问题变成生产契约问题

当前问题

同一需求重复生成时，角色、风格、材质和构图仍会漂移；固定资产若继续交给模型重画，结果天然不可控

核心机制

视觉契约定义必须保持 / 允许变化 / 禁止出现、参考资源、身份锁、执行模式和验收标准；MCP 按任务编译契约指纹，统一下发、登记、检查和复核

验证边界

固定资产可通过原资产直接复用与模型外拼装实现像素级一致；生成区域只能提高合格率。当前机制已运行，跨模型、跨 Agent 和大规模任务稳定性尚未证明

视觉契约执行链

契约定义边界，MCP 负责执行、留痕与验收

需求分类
编译视觉契约
锁定契约版本
下发参考与生产单元
按模式生成 / 拼装并登记
系统检查 + 独立验收
现在 已发布视觉契约、MCP 任务编排、生成登记与验收机制已具备；部分小黄鸡、金币和主题组合已验证目标 同类任务重复执行时，固定资产不漂移，角色与风格合格率可测，结果可追溯、可复核

近期只抓三件事

先证明稳定，再扩大生产范围

P0

固定资产不再重画

金币、按钮、字体、角标和品牌元素标记为原资产直接复用，由 MCP 在模型外直接拼装或覆盖

P0

提高契约合格率

按参考图组、角色身份锁和视觉验收标准统计首轮通过率、重试次数和独立验收结果

P1

证明稳定后再扩范围

先验证同一契约在重复任务中的稳定性，再扩到更多模型、Agent、工具和正式生产任务

事实边界 已实现的是“视觉契约 + MCP 执行协议 + 结果登记 + 验收门禁”的机制闭环；这不等于已经消除模型随机性，也不代表已完成公司级规模化生产
